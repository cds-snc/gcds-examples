Accueil Bienvenue dans l'application de démarrage HTML qui exploite les composants du Système de design GC ! Ce modèle d'application de démarrage est conçu pour aider les développeurs à configurer rapidement un site HTML simple tout en adhérant aux normes d'accessibilité et de conception définies par le gouvernement du Canada. Chaque page est un fichier HTML autonome qui charge les composants GCDS directement depuis le CDN — aucune étape de compilation, aucun regroupeur, aucune installation npm requise. Copiez ce dossier, modifiez le HTML, et c'est prêt.
