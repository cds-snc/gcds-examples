Home Welcome to the HTML Starter App that leverages GC Design System components! This starter app template is designed to help developers quickly set up a plain HTML site while adhering to the accessibility and design standards set by the Government of Canada. Every page is a standalone HTML file that loads GCDS components directly from the CDN. No build step, no bundler, no npm install required. Copy this folder, edit the HTML, and you're up and running.
