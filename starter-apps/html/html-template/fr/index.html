Accueil Bienvenue dans le modèle de démarrage HTML qui utilise les composants de Système de design GC! Ce modèle de démarrage est conçu pour aider les développeurs et développeuses à configurer rapidement un site HTML moderne tout en respectant les normes d'accessibilité et de conception du gouvernement du Canada. Vous y trouverez des pages HTML simples, Vite pour le développement local et les builds, Playwright pour les tests de bout en bout, ainsi qu'une sélection de composants Web GCDS pour démarrer votre projet.
